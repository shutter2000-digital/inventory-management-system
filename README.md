# Inventory Management System

Company-approved internal inventory digitalization project for Shutter 2000 Plus (Pvt) Ltd. Planned stack: React + TypeScript + Vite, ASP.NET Core Web API (.NET 10), EF Core and PostgreSQL. The frontend and backend remain in this single product repository.

## Status
Initial repository scaffold only. No framework, application, deployment or automated checks have been initialized.

## Structure
See the repository folders and [AGENTS.md](AGENTS.md) for architectural boundaries and contribution rules.

## Getting started
The team should agree on requirements, initialize the required tooling, commit lockfiles and document reproducible setup, run and test commands here. Do not add production credentials.

## Contributors and handover
Track individual work through issues and reviewed PRs. Record actual contributions and maintain approved setup, demo and handover instructions. Publication and licensing require company approval.
